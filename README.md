# RetailIQ | Sales & Returns Analytics

A Power BI project focused on understanding retail sales performance, revenue trends, and product returns using transactional data from 2010–2011.

## Project Overview

RetailIQ helps explore sales performance across countries, monitor product returns, and identify revenue trends through an interactive Power BI dashboard.

## Tools & Technologies

- **Power BI Desktop** — Dashboard development and data visualization
- **DAX** — Measures and KPI calculations
- **PostgreSQL** — Data storage and querying
- **Power Query** — Data preparation and transformation

## Dashboard Pages

### 1. Sales & Returns Overview
- Total sales revenue and net revenue
- Total transactions, units sold, and units returned
- Monthly sales and net revenue trends
- Country-wise revenue comparison
- Top products by revenue and returned units

### 2. Product Performance
- Product-level sales and returns analysis
- Product return rate comparison
- Country and date filters
- Transaction-level details

## Key Skills Demonstrated

- Data modelling and relationships
- DAX measures and KPI reporting
- Interactive dashboard design
- Sales and returns analysis
- Business-focused data visualization

## Project Files

- `.pbix` — Power BI report and working model
- `.pbit` — Reusable Power BI template
- `.pdf` — Exported dashboard report

## Project Goal

To turn raw retail transaction data into an interactive report that makes sales performance and product returns easier to explore.
